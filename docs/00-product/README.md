# Product Baseline

## Layanan MVP

1. NPWP Perseorangan — aktif setelah requirement dan harga valid.
2. NPWP Badan Usaha — aktif setelah requirement dan harga valid.

Lapor Pajak hanya `COMING_SOON`; tidak memiliki form, payment, upload, workflow, harga, requirement aktif, atau integrasi.

## Non-goals

Sistem bukan sistem resmi pemerintah dan tidak mengakses DJP/Coretax, credential, OTP, OCR, AI document verification, facial recognition, atau biometrics.
